# Checkpoint payload support

Schema compatibility and payload interoperability are separate claims. SQLite uses
the standard `checkpoints` and `writes` tables. PostgreSQL preserves migrations 0
through 9 and the standard checkpoint, blob, and write tables.

| Value | Encoding | Python/Go safe subset |
|---|---|---|
| null | `null` | yes |
| booleans, integers, floats, strings | MessagePack | yes |
| bytes | `bytes` or `bytearray` | yes |
| lists and string-keyed maps | MessagePack | yes |
| checkpoint envelope and metadata | versioned plain records | yes |
| message, tool call/result, removal marker | `dago.message.v1` plain record | yes with the supplied Python adapter |
| overwrite command | `dago.overwrite.v1` plain record | yes with the supplied Python adapter |
| delta snapshot | MessagePack extension 7 | yes; payload is recursively safe MessagePack |
| pickle | rejected | no |
| arbitrary constructor or method extensions | rejected | no |
| Pydantic, NumPy, callable, or import records | rejected | no |
| unknown MessagePack extension or record tag | rejected | no |

Unsupported values return `serde.CompatibilityError` with checkpoint ID, channel,
and encoding. They are never guessed, dropped, imported, constructed, or executed.
The Python fixture adapter recognizes only the record tags in this table.

The checked-in SQLite fixture is generated by
`conformance/python/checkpoint_interop.py` against the pinned Python saver. Run
`make checkpoint-interop` to regenerate a Python-owned database, read and continue it
in Go, create a Go-owned database, and read and continue that database in Python.
The test includes delta snapshot extension 7 and never uses pickle or constructor
records.

PostgreSQL uses the same safe payload codec and participates in the bidirectional
fixture gate when `DAGO_POSTGRES_TEST_DSN` points to a disposable database. The
Python-owned and Go-owned threads are read and continued by the other runtime;
migration rows, indexes, pending-write ordering, blob precedence, delta history,
copy, and prune behavior are asserted by the saver suite.
